About AFLCP Project

Asynchronous Federated Learning with Communication Preservation for Cardiovascular Disease Prediction

school

Project Overview

Final Year Research Project

AFLCP is a novel framework that combines Asynchronous Federated Learning with Communication-Efficient techniques for privacy-preserving cardiovascular disease prediction.

The system enables multiple healthcare institutions to collaboratively train a shared AI model without sharing sensitive patient data, addressing both privacy concerns and the need for large-scale datasets in medical AI.

security

Privacy Preservation

Raw patient data never leaves local institutions. Only encrypted model updates are shared.

sync

Asynchronous Updates

Clients can update independently without waiting, improving training efficiency.

compress

Communication Efficiency

Top-K sparsification and deep/shallow exchange reduce bandwidth requirements.

psychology

FedProx Optimization

Handles statistical heterogeneity across clients with proximal term regularization.

shield

Differential Privacy

Optional DP noise addition for mathematically guaranteed privacy.

favorite

CVD Prediction

Accurately predicts cardiovascular disease risk from clinical parameters.

How It Works

1

Data Stays Local

Each institution keeps patient data on their own servers

2

Local Training

Model is trained locally on each client's data

3

Share Updates

Only model weights (not data) are sent to server

4

Global Model

Server aggregates updates into improved model

dataset

Dataset

This project uses the Heart Disease UCI dataset containing 13 clinical features including age, sex, chest pain type, blood pressure, cholesterol, fasting blood sugar, ECG results, maximum heart rate, exercise-induced angina, ST depression, slope, major vessels, and thalassemia status.
